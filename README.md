# SYSTEM Launcher

**SYSTEM** é um launcher desktop para Windows, desenvolvido por Sant2ZX.

## Versão
0.4.0

## Recursos
- Interface desktop desenvolvida com Electron.
- Ferramentas de configuração do Roblox.
- Gerenciamento de FastFlags.
- Diagnóstico de hardware e desempenho.
- Ferramentas de personalização.
- Sistema de configurações locais.
- Integração com recursos da comunidade.

## Instalação
1. Acesse a seção Releases deste repositório.
2. Baixe SYSTEM-Setup-0.4.0.exe.
3. Execute o instalador.
4. Siga as instruções na tela.

## Desenvolvimento
Requisitos: Node.js LTS e npm.

Instalar dependências: npm install

Executar: npm start

Gerar instalador: npm run dist

## Observações
O SYSTEM não garante aumento de FPS. O comportamento das FastFlags depende das políticas e versões atuais do Roblox.
